# Changelog

All notable changes to this project are documented in this file.

## 2026-10-02

- Replaced the single-message placeholder with a responsive CKC Woodworks coming-soon page using the existing serif fonts and an ivory, navy, brass, and sage palette.
- Added a new website announcement, a decorative moulding study, accessible click-to-call and email links, and the St. Louis address with a Google Maps link.
- Featured Moulding Saint Louis as CKC's new residential division with a link to `mouldingstl.com`.
- Updated metadata and the canonical URL to `ckcwoodworks.com` while retaining all temporary no-index and crawler-blocking controls.
- Updated the README to describe the new placeholder and production domains.

## 2026-08-26

- Initialized the CKC website as a Next.js 16, TypeScript, and Tailwind CSS v4 application.
- Added the responsive **Coming Soon!** placeholder page for `ckc.mouldingstl.com`.
- Added `noindex, nofollow` metadata and a crawler-blocking `robots.txt` policy for the temporary testing page.
- Replaced the initial README with setup, deployment, and maintenance guidance aligned to the existing Moulding Saint Louis website.
