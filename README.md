# CKC Woodworks

Marketing website for CKC Woodworks, a St. Louis commercial millwork and cabinetry shop.

## Local development

```bash
pnpm install
pnpm dev
```

## Validation and production build

```bash
pnpm check
pnpm build
```

The site is configured for Vercel. `vercel.json` preserves direct access to all client-side routes. `public/robots.txt` permits indexing and links to `public/sitemap.xml`.
